1. Project Overview & Motivation

The AI-Based IoT Cyberattack Detection System (AEGIS-IoT) is a cutting-edge cybersecurity platform designed to safeguard resource-constrained Internet-of-Things (IoT) environments from sophisticated multi-stage cyber threats.

With billions of interconnected IoT nodes deployed globally across smart homes, industrial plants, hospitals, and smart cities, IoT networks have become prime targets for malicious actors. AEGIS-IoT bridges the gap between complex network flow telemetry and real-time defense through an intelligent, explainable Machine Learning pipeline paired with an enterprise Security Operations Center (SOC) dashboard.

2. Problem Statement

Resource Constraints: IoT devices (microcontrollers, sensors, smart bulbs) lack the CPU, RAM, and battery power to run traditional heavy endpoint antivirus software.
Insecure Default Configurations: Many consumer and commercial IoT devices ship with hardcoded credentials (admin/admin), unpatched firmware, and exposed Telnet/SSH ports.
Weaponization as Botnets: Compromised IoT devices are weaponized into massive botnet armies (e.g., Mirai, Gafgyt) capable of launching crippling multi-terabit DDoS assaults.

3. End-to-End System Architecture

FLOW PIPELINE
Phase 1: Ingestion

Captures network traffic traces (PCAP / live sockets) from IoT sensors & edge gateways.

Phase 2: Preprocessing

Calculates 18 flow statistical features (rates, durations, flag ratios) & standardizes scales.

Phase 3: ML Inference

Random Forest Classifier predicts attack class & outputs true probability distribution.

Phase 4: SOC Response

Dispatches MITRE-mapped alerts, updates SQLite records, and renders real-time telemetry.

5. Why Random Forest Classifier?

While Deep Neural Networks (CNN/LSTM) are powerful, Random Forest was specifically selected for IoT intrusion detection due to compelling architectural advantages:

  • Ultra-Low Latency Inference: Deciding through decision trees requires mere microseconds (<1ms), making it viable on edge routers where deep learning would cause unacceptable packet queuing.
  • Non-Linear Flow Boundary Separation: Network features (SYN flags, packet lengths, flow durations) exhibit sharp threshold transitions that orthogonal decision splits capture better than hyperplanes.
  • Resistance to Overfitting: Bootstrap aggregation (bagging) and random feature sub-sampling prevent trees from memorizing noise.
  • Explainable Feature Importances: Outputs concrete Gini impurity metrics, allowing security analysts to inspect exactly which flow attributes triggered the alert.
